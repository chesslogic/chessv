# Adopt hybrid material recalibration

Type: grilling  
Status: resolved

## Question

Should new Location and checkmate material targets be purely derived or purely hand-authored?

## Answer

Use a hybrid contract.

1. Compute a reproducible first estimate from the catalog-value delta between the old CPU formation and the resolved augmented formation.
2. Preserve existing hand-authored Location values as compatibility/calibration inputs rather than pretending they were generated by that estimate.
3. Apply explicit authored offsets, monotonic constraints, and later play-test calibration to produce released thresholds.

The map must still settle the exact value basis, role weighting, family aggregation, rounding, monotonicity, and storage format. Running play tests is downstream; defining how their results may alter authored offsets is in scope.
